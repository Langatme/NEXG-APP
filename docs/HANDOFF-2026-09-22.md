## 5. Six traps that have already cost real time

Not style preferences. Each caused a wrong answer, a wasted hour, or a silent failure.

### 5.1 A green gate is not working software

`tsc` reported clean while **add-to-cart was dead on five pages**, because `@types/react` was
missing and errors vanished. Installing it exposed **19 live defects** in one run.

**Never remove `@types/react` or `@types/react-dom`.**

### 5.2 A clean scan is not evidence without a control

The detector timed out on every URL scan, **exited 0, and printed `[]`** — a failed scan was
byte-identical to a clean one, and 22 such results were reported as passes. **Always run a
known-bad input in the same run.**

### 5.3 `skip-worktree` hides changes from git AND `git archive`

`index.html` carried the `S` flag. A rebrand edit lived only in the working copy, was never
committed, and **every deploy shipped stale HTML while all gates stayed green**.

If a deploy serves the wrong content but the source looks right: `git ls-files -v <file>`.
**Do not re-add the flag.**

### 5.4 The build happens INSIDE the Docker image

There is **no `dist/` on the server.** An earlier deploy script checked the host filesystem and
**reported zero occurrences because the path did not exist** — a failed check identical to a
clean one. Verify against the running container:

```bash
docker exec nexg-concierge-app-1 sh -c 'ls /app/dist/assets'
```

### 5.5 PowerShell 5.1 corrupts, mangles and misleads

- **`>` re-encodes binary as UTF-16.** Streaming a tar produced `FF FE 1F 00` instead of
  `1F 8B 08` and inflated 63 MB to 120 MB. **Use `cmd /c "... > file"`.**
- **`Out-File`/`Set-Content` are not UTF-8.** Use
  `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($false)))`.
- **It eats quotes, backticks and em-dashes.** A commit message containing `→` dies with
  `error: unknown switch`. **Write the message to a file and use `git commit -F`.**
- **Its console renders valid UTF-8 as mojibake**, which twice looked like file corruption.
  **Verify at byte level.**
- **Inline `node -e` with nested quotes fails.** Write a `.mjs` file instead. This wasted four
  attempts in one session.

### 5.6 Node 24 runs `server/*.ts` in STRIP-ONLY mode

Constructor parameter properties, `enum`, `namespace` and decorators throw
`ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX` **at import time and kill the process**, while
`tsc --noEmit` passes happily. **After any `server/` change, actually boot it.**

## 6. Instrument traps that produced wrong answers

- **Canvas returns opaque black for `oklch()`** — it cannot parse it. Two colour probes gave
  confidently wrong results. **Read raw computed values.**
- **`window.scrollTo` reports `scrollY: 0` when an input holds focus.** Use `mouse.wheel`.
- **`height / line-height` is not a line count.** Use `Range.getClientRects()`.
- **`scp -r` is slow for many small files** — 10,510 files took over 10 minutes. Tar over SSH.
- **A temp-dir script cannot `require('playwright')`.** Keep scripts inside the project.
- **Don't compute SVG bounds by parsing path data.** Relative commands make it meaningless —
  producing negative coordinates for a shape in the positive quadrant. Use `getBBox()` or an
  alpha scan, or render each element and look.

- **One animation library per component subtree.** Motion and react-spring both write
  `transform`; two writers on one node means the last one wins.
- **Never put `127.0.0.1` in the container's `DATABASE_URL`.** Inside the app container that is
  the container itself, so the app silently serves the bundled JSON catalogue while reporting
  healthy. Use the compose service name `postgres`.
